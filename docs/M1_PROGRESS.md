## 实现批次

- 网格批次：19 项检查通过，覆盖边界、占位、方向、价格、唯一设施及空载拆除退款。
- 物流批次：固定 10 Hz 模拟、两条配方、快照容量仲裁、分流与汇流、有限仓储和交付缓存；包含命令边界验证的 14,927 项检查通过，其中大量为逐步守恒断言，不代表同等数量的独立测试场景。

- 双炉夹具注入 1000 初始测试资金；物流搭建后余额 280。无限测试供电不收取 M2 的 240 扩容费，这不是订单奖励或真实供电实现。
- 测试收集开关默认关闭；开启后将交付缓存移入测试累计计数，不出售、不奖励，用于持续吞吐量和堵塞恢复验证。守恒统计包含该计数。
- 交互批次：原生 Godot 界面、原创临时像素图标、建造预览、旋转拆除、开关、状态检查和夹具切换；25 项 UI 冒烟检查通过。

## 操作

| 操作 | 行为 |
| --- | --- |
| 右上角播放 / Space | 正常速度运行或暂停，无加速模式 |
| 左侧建筑工具，点击或拖动空格 | 放置建筑；原料仓只能在 (2, 7)，各建筑价格在工具提示中 |
| 右键建筑 / Inspect 工具 | 选中并显示输入、输出、产量、加工进度与状态 |
| 旋转图标 / R | 建造模式改变朝向，检查模式旋转选中的空建筑 |
| 删除图标 / Delete | 拆除选中的空建筑并全额退款；含货物或在制品时拒绝 |
| Enabled 开关 | 停止供料或加工；关闭原料仓后仍可排空已有矿石 |
| 仓储物品菜单 | 只允许空仓切换铁矿石、铁板、零件 |
| 夹具菜单 + Load fixture | 确认后替换布局，重置测试计数和资金 |
| Test collector | 将交付缓存转入测试累计计数，便于持续测试吞吐量 |

运行中编辑按提交顺序在下一个逻辑步执行；暂停时编辑立即执行。若点击暂停时尚有待提交命令，则先完成一个逻辑步再暂停，避免队列与暂停编辑次序颠倒。暂停本身不清空库存或加工进度。

默认铁板夹具已建好并暂停；完整 M0 关卡应从空图开始，两者不混淆。四种夹具分别为铁板线、单炉零件线、双炉零件线、空图。小窗口侧栏可滚动，画布自适应，文本保持原生字号。最小窗口为 960x640。
