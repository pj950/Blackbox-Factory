核心循环：发现瓶颈 → 改造生产线 → 提高吞吐量 → 解锁更复杂的生产链。

## 启动与复测

在工作区根目录的 PowerShell 中运行：

```powershell
.\scripts\godot.ps1 -Action Play
.\scripts\godot.ps1 -Action Test
.\scripts\godot.ps1 -Action Smoke
```

本机便携引擎已放入 `.tools/godot-4.7.2/`。其他机器需要自行下载同版本标准版，或用 `-GodotPath` 指定可执行文件；脚本不会自动安装软件或修改执行策略。`Play` 打开游戏，`Test` 运行无界面逻辑测试，`Smoke` 打开短时测试窗口、生成两种尺寸截图并退出。`Editor` 可打开编辑器。

也可使用 Godot 4.7.2 导入 [game/project.godot](game/project.godot) 并运行主场景。默认进入暂停的空图合同模式：接受 O1，用初始 800 资金建立铁板线，再播放模拟。建造、检查和排空转产的操作见 M1/M2 文档；侧栏的 Scenario 菜单仍保留独立测试夹具。

合同模式使用 10 功率，240 资金可一次性扩容至 14；完成订单获得奖励，超额库存不出售。测试收集器仅用于测试夹具。新合同的机器会按获电加工时间磨损，提前预警，达到阈值后半速；检查机器后可花费 40 资金进行 10 模拟秒的停机维修，保留在制品。

F5 或顶部保存图标手动保存；F9 或读档图标确认后加载，成功后保持暂停。只有一个手动槽，**没有自动保存，退出前请主动保存**。Windows 存档通常位于 `%APPDATA%/BlackboxFactoryPrototype/saves/slot1.json`，损坏时可恢复上一份有效 `.bak`。不要同时从多个游戏窗口写入同一存档槽。详细限制见 M3 文档。
